# SoftAP 配网方案实施总结

**实施日期**：2026-04-19
**状态**：✅ 完成
**方案来源**：`docs/智能相册-SoftAP配网与动态绑定方案调研-2026-04-18.md`

## 📊 改造概览

本次改造将原有的 **BLE 配网方案** 替换为 **SoftAP + 本地网页 + 动态绑定码** 方案，完全按照调研文档的推荐方案实施。

### 主要变更

| 模块 | 原方案 | 新方案 |
|------|--------|--------|
| 配网方式 | BLE GATT | SoftAP + HTTP 网页 |
| 绑定方式 | MQTT 握手 | HTTPS + 动态绑定码 |
| 用户交互 | 扫码 + BLE 连接 | 连接热点 + 打开网页 |
| 浏览器兼容性 | 依赖 Web BLE | 无特殊要求 |

```c
typedef enum {
    BIND_STATUS_UNBOUND = 0,
    BIND_STATUS_PENDING = 1,

    BIND_STATUS_EXPIRED = 3

typedef struct {

#### 1.2 创建 SoftAP 配网组件

**新增组件**：`firmware/components/softap_prov/`

**核心功能**：
- ✅ SoftAP 热点创建（APSTA 模式）
- ✅ HTTP 服务器（端口 80）
- ✅ Wi-Fi 扫描功能
- ✅ 配网页面（HTML/CSS/JS）
- ✅ 状态管理和屏幕显示

**API 接口**：
- `GET /` - 配网页面
- `GET /api/scan` - 扫描附近 Wi-Fi
- `POST /api/connect` - 提交 Wi-Fi 凭证
- `GET /api/status` - 查询配网状态

**配网页面特性**：
- 🎨 现代化 UI 设计
- 📱 响应式布局
- 🔄 实时 Wi-Fi 扫描
- 🔐 MQTT 可选配置
- ⏳ 状态反馈

#### 1.3 改造主程序流程

**文件**：`firmware/main/main.c`

**关键变更**：
- 替换 `ble_prov.h` → `softap_prov.h`
- 替换 `enter_ble_prov_mode()` → `enter_softap_prov_mode()`
- 新增 HTTPS 绑定码请求功能
- 新增绑定码显示逻辑

**配网流程**：
1. 设备开机无配置 → 进入 SoftAP 模式
2. 创建热点（SmartFrame-{后4位}）
3. 显示配网页面 IP 地址
4. 用户连接热点，打开网页
5. 扫描 Wi-Fi，选择并输入密码
6. 设备连接家庭 Wi-Fi
7. 向服务器请求绑定码
8. 在墨水屏显示 6 位绑定码
9. 用户在云平台输入绑定码
10. 绑定成功，设备重启进入正常模式

    "used_at": null,
    "user_id": null
  }
}
```

#### 2.2 新增 API 接口

**文件**：`server/main.py`

**新增接口**：

##### 1. 申请绑定码
```
POST /api/devices/{device_id}/bind-code
```

**响应**：
```json
{
  "bind_code": "123456",
  "expires_at": 1713518700,
  "device_id": "A1B2C3D4E5F6G7H8"
}
```

**特性**：
- 生成 6 位数字绑定码
- 5 分钟有效期
- 一次性使用
- 状态追踪

##### 2. 绑定设备（升级）
```
POST /api/bind
```

**改进**：
- ✅ 优先从 bind_codes.json 查找
- ✅ 支持绑定码过期检查
- ✅ 支持绑定状态管理
- ✅ 向后兼容旧数据结构

## 🔧 技术实现细节

### SoftAP 配置

- **热点名称**：`SmartFrame-{device_id后4位}`
- **热点密码**：无（开放网络）
- **IP 地址**：`192.168.4.1`
- **频道**：1
- **最大连接数**：4

### 绑定码规则

- **格式**：6 位数字
- **示例**：`123456`
- **有效期**：5 分钟（300 秒）
- **使用次数**：一次性
- **存储位置**：服务器 `bind_codes.json`

### HTTP 服务器

- **端口**：80
- **并发连接**：支持多客户端
- **资源嵌入**：HTML 文件嵌入固件
- **错误处理**：完整异常捕获

### Wi-Fi 扫描

- **扫描模式**：主动扫描
- **返回数量**：最多 20 个
- **信息包含**：SSID、信号强度、频道、加密方式

### 配网注意事项

1. **首次配网**：
   - 确保设备已格式化 SD 卡
   - 删除旧 `config.txt` 文件
   - 重启设备进入配网模式

2. **网络要求**：
   - 家庭 Wi-Fi 需要支持 2.4GHz
   - 确保服务器地址可访问
   - 检查防火墙设置

3. **绑定码有效期**：
   - 5 分钟内必须完成绑定
   - 过期后需要重新配网
   - 绑定码只能使用一次

## 📞 技术支持

### 常见问题

**Q1: 配网页面无法打开？**
A: 检查手机是否正确连接到设备热点，IP 地址应为 192.168.4.1

**Q2: Wi-Fi 扫描不到网络？**
A: 确保设备支持 2.4GHz Wi-Fi，且信号强度足够

**Q3: 绑定码无效？**
A: 检查绑定码是否在 5 分钟有效期内，且未被使用

**Q4: 设备无法连接家庭 Wi-Fi？**
A: 检查 Wi-Fi 密码是否正确，确认路由器支持 2.4GHz
